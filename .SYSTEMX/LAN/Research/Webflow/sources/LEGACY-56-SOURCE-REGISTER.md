# Legacy 56-Source Register Assessment

The existing repository file `.SYSTEMX/LAN/WEB-BUILDER-UX-RESEARCH.md` contains an earlier 56-source interaction-oriented register. It was useful for the LAN shell, toolbar geometry, and builder UX baseline.

This package does not duplicate that file verbatim because it remains available in the repository and can drift independently. Instead, the new catalog supersedes it for the master plan with exactly 200 source records and expands coverage into:

- document identity and commands;
- CSS cascade/breakpoints/variables;
- components/props/slots/variants/libraries;
- CMS schemas/relationships/queries/bindings;
- interactions and localization;
- roles/comments/branches/activity/backups;
- publication, domains, search, forms, Ecommerce;
- Analyze/Optimize and AI;
- Designer/Data/Browser APIs, Apps, Code Components, Cloud, DevLink, Flowkit, CLI, MCP;
- normative web/data/accessibility/security standards;
- comparator architecture patterns.

Recommended repository action: retain the legacy file as historical UX research, add a superseded-by link to the new master plan, and avoid counting overlapping URLs as independent evidence in future source totals.
