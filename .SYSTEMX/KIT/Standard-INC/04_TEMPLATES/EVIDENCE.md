## Required mail test coverage

Record a result for every Info/Chef mailbox and all seven aliases in each business; include NoReply outbound authentication, Reply-To and inbound handling. Test wrong-business isolation and forwarding loops. Record current DNS evidence and recovery access separately from message delivery.

## Optional website / brand coverage

Record Hosting project/site association, domain ownership, TLS and canonical/redirect behavior. Link approved asset source, license, manifest/checksum and Brand/Production output checks. Empty website configuration makes website tests not applicable with a reason.

## Change record

Record previous state/backup, intended changes, approver, implementation time, rollback trigger, restore result and final owner. Keep private message contents and personal data in access-controlled evidence storage.
