# Release notes

## 1.0.0

Expanded the supplied portfolio example into an INC setup kit with intake, email operations, blank portfolio configuration, read-only validation, evidence and handoff templates.

Corrected the illustrative Drive layout to named `.SYSTEMX/Projects/<name>/.SYSTEMXP` records. Business metadata remains separate from the manager-owned registry. Existing Brand and Production kits contribute workflow and asset provenance patterns; their protected artwork remains unchanged.

Adoption of earlier examples requires a reviewed mapping to registered projects. Back up existing records and create missing scopes through the supported project manager; do not move old folders or overwrite custom records automatically.
