# Layer Map

The layered master preserves the current approved raster artwork. It does not reinterpret the logo.

| Layer | Visibility purpose |
|---|---|
| Background | Pure white production background |
| Logo | Protected W, world map, and arc symbol |
| Wayne | WAYNE wordmark |
| Tech Lab | TECH LAB wordmark and side rules |
| Services | FinTech / Enterprise I.P. / Worldwide Branding / A.I. Automation line and divider rules |

## Official layer-state exports

1. **Logo** - Logo layer only.
2. **Wayne** - Logo + Wayne.
3. **Tech Lab** - Logo + Wayne + Tech Lab.
4. **ALL Text** - Logo + Wayne + Tech Lab + Services.

Open `WTL_Master_Layered.svg` in Figma, Illustrator, Affinity Designer, or Inkscape. Open `WTL_Master_Layered.ora` in Krita or GIMP. Toggle layer visibility; do not redraw the protected artwork.
