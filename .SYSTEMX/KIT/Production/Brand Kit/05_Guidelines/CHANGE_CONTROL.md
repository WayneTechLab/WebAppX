# Brand Change Control

1. Treat the source-lock checksum as the approval baseline.
2. Create new deliverables from the layered master or supplied exports.
3. Record requested changes in a new version folder; never overwrite the source-lock folder.
4. Obtain written approval before changing the protected symbol, map, arc, gradients, or wordmark composition.
5. Reissue checksums and an updated manifest with every approved release.
