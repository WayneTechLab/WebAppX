# Official Logo Exports

## 4K layer-state files

The white-background and transparent folders each contain four 4096 x 2731 PNG files produced from one protected master canvas:

- `Logo.png` - symbol layer only.
- `Wayne.png` - symbol + WAYNE.
- `Tech Lab.png` - symbol + WAYNE + TECH LAB.
- `ALL Text.png` - complete identity and service line.

The position and scale of visible elements are preserved between these exports. For a centered square app/profile mark, use the 4096 x 4096 files in `Square/`.

`Components/` provides tight transparent crops. `SVG_Exports/` provides scalable embedded-raster SVGs that preserve the approved source pixels.
