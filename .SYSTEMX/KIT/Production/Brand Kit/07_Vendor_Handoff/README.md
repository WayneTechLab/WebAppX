# Vendor Handoff

Provide the vendor with:

1. The requested official PNG or SVG export.
2. `PRODUCTION_SPEC.md`.
3. The source-lock checksum when approval traceability is required.

For print, preserve aspect ratio and convert to the vendor's requested CMYK profile only at final prepress. Request a proof before mass production. Do not permit redrawing, auto-tracing, font substitution inside the approved mark, or proportion changes.
