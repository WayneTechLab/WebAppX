# Wayne Tech Lab LLC. Master Production Kit v1.0

This release contains the approved Wayne Tech Lab source logo, exact layer-state exports, layered editing masters, brand and media kits, platform asset packages, implementation code, and a professional executive document system.

## Protected source

The authoritative source is stored under `00_Source_Locked/`. Read `SOURCE_LOCK.md` before editing or producing derivative files. The W/globe symbol, world map, arc, proportions, gradients, wordmark placement, and service-line composition must not be redrawn or changed without written approval.

## Four official 4K variants

1. **Logo** - protected symbol only.
2. **Wayne** - symbol plus WAYNE.
3. **Tech Lab** - symbol plus WAYNE and TECH LAB.
4. **ALL Text** - complete identity with `FinTech | Enterprise I.P. | Worldwide Branding | A.I. Automation`.

Each version uses the same 4096 x 2731 master canvas. The only difference is layer visibility.

## Layered masters

- `WTL_Master_Layered.svg` - Figma, Illustrator, Affinity Designer, and Inkscape friendly.
- `WTL_Master_Layered.ora` - Krita and GIMP friendly.
- `Layers/` - independent full-canvas PNG layers.

## Included systems

- Brand Kit: logos, colors, typography guidance, design rules, production specifications, and tokens.
- Media Kit: company fact sheet, boilerplate, contact information, social assets, Open Graph art, and email signature.
- WebAPP: PWA icons, favicon, PNG/WebP/SVG exports, manifest, CSS, and a React component.
- iOS: complete AppIcon set, BrandLogo imageset, and SwiftUI brand colors.
- Android: legacy and adaptive launcher assets, Play Store icon, colors, and Compose tokens.
- Standard Document Set: editable DOCX and DOTX templates plus verified PDF previews.

## Typography

The approved logo lettering is preserved as raster artwork. A reusable companion type system based on Inter is documented, but font files are intentionally not bundled.

## Integrity

Use `CHECKSUMS.sha256`, `MANIFEST.json`, or `MANIFEST.csv` to verify files after transfer or archive storage.
