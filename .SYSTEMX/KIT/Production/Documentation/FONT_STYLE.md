# Wayne Tech Lab Typography System

## Source-logo note

The approved source image contains rasterized lettering. It is not connected to a recoverable font file. The production kit therefore preserves the approved lettering as image layers and specifies a reusable companion type system for documents, websites, applications, and future editable layouts.

## Recommended reusable font

**Primary:** Inter

- WAYNE-style display headings: Inter Display SemiBold or Bold, uppercase.
- TECH LAB-style labels: Inter Medium, uppercase, with increased tracking.
- Service-line and interface text: Inter Regular or Medium.
- Documents: Arial is the compatibility fallback; Aptos or Inter may be used when installed.

Inter provides a normal uppercase A, strong screen readability, broad platform support, and a neutral executive technology appearance.

## Suggested settings

| Role | Typeface | Weight | Case | Tracking |
|---|---|---:|---|---:|
| Display / WAYNE companion | Inter Display | 700 | Uppercase | 0.03em |
| Submark / TECH LAB companion | Inter | 500 | Uppercase | 0.32em |
| Service line | Inter | 400-500 | Title case | 0.01em |
| Document headings | Arial / Inter | 700 | Title case | 0 |
| Body | Arial / Inter | 400 | Sentence case | 0 |

## Font handling

Font files are intentionally not bundled. Use a locally licensed installation, a system font stack, or a trusted web-font delivery method. Do not substitute the protected raster wordmark inside the approved logo assets.
