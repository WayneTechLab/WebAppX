# Asset Manifest Guide

The machine-readable root `MANIFEST.json` lists all files, dimensions, file sizes, and SHA-256 checksums. `CHECKSUMS.sha256` supports command-line verification.

Primary asset locations:

- `00_Source_Locked/` - immutable approval baseline.
- `Brand Kit/01_Logos/` - official variants and formats.
- `Brand Kit/02_Layered_Master/` - editable visibility layers.
- `Media Kit/` - press, social, email, and presentation-ready exports.
- `WebAPP/`, `iOS/`, `Android/` - platform packages.
- `Standard Document Set/` - executive document templates and PDF previews.
