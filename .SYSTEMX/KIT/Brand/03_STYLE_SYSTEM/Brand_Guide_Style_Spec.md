# Brand Guide Style System

## Core visual language

- Six-page US Letter portrait booklet.
- Warm-white background with restrained ink coverage.
- Thin double gold border inset from the trim edge.
- Elegant editorial serif for page titles and long-form copy.
- Client-derived accent color for section numbers and headings.
- Supporting all-caps sans-serif for labels and technical notes.
- Generous white space and a clear, balanced grid.
- Small producer mark in interior footers; large producer mark on the back page.

## Logo and font rule

The supplied client logo is the source of truth. Do not redraw, restyle, recolor, stretch, or substitute its lettering. The Bardo's script and BB block lettering in the example are artwork contained in the logo, not confirmed font files. Use the supplied typography reference crops when an LLM needs a visual style cue.

When a client provides source font names, list them as confirmed. When only a raster logo is available, state `custom logo lettering` and list closest production alternatives separately without claiming they are exact.

## Publication typography

- Display serif: Cormorant Garamond, Libre Baskerville, or a comparable high-contrast serif.
- Supporting sans: Montserrat, Source Sans 3, or Helvetica fallback.
- Section heading: bold, uppercase, client-primary accent.
- Body copy: 10.5-12 pt equivalent, dark neutral, 1.35-1.55 line height.
- Footer copy: 8.5-9.5 pt equivalent.
- Never place body text below 9 pt.

No font files are included in this template. Install or license the preferred typefaces separately.

## Print geometry

- Trim: 8.5 x 11 inches.
- Recommended render: 2550 x 3300 px at 300 DPI.
- Safe area: at least 0.5 inch from every trim edge.
- Decorative border: no closer than 0.25 inch to trim and must remain thin.
- No full-bleed color bars by default.
- Keep headers, footers, logos, and page numbers inside the safe area.
- Avoid text over images unless contrast is verified.

## Footer standard

`Produced by {producer_name} for {client_display_name}`

Page number: `{n} of 6`

The producer logo must be inserted from the supplied file and must not be regenerated.
