# Typography Mapping

## Client logo lettering

1. Primary wordmark: use the exact wordmark contained in the supplied logo artwork.
2. Block abbreviation: use the exact block letters contained in the supplied logo artwork or a client-approved extracted asset.
3. Tagline: use a heavy all-caps sans with open counters and consistent tracking.

For the Bardo's example:

- `Bardo's` is treated as custom script artwork. Closest references: SignPainter House Script, Thirsty Script, or Lobster Two. These are references only, not confirmed source fonts.
- `BB` is treated as custom slab/block artwork. Closest references: Rockwell Extra Bold, Clarendon Black, or College Block. These are references only, not confirmed source fonts.
- `BREAKFAST & BURGERS` uses a bold all-caps sans style similar to Montserrat ExtraBold.

## Booklet typography

- Main page titles: classic high-contrast serif, 28-38 pt.
- Large page numbers: same serif, client accent color, 28-46 pt.
- Section labels: bold all-caps sans, 12-16 pt.
- Body: readable serif, 10.5-12 pt.
- Technical labels: supporting sans, 8.5-10 pt.

Never package or distribute font files with this template. Provide names and licensing notes only.
