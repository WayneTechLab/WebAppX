# WebAppX ownership and contribution notes

[WayneTechLab](https://github.com/WayneTechLab) is the sole owner and maintainer
of [WebAppX](https://github.com/WayneTechLab/WebAppX). No other repository
collaborator is added at publication.

WebAppX starts with fresh Git history exported from the reviewed source
template. Previous repository contributor commits are not part of this history.
Required licenses and upstream source attribution are retained.

Public visibility allows reading, cloning, forking and suggesting changes.
It does not grant repository write or administrative access. WayneTechLab alone
controls invitations and approval of changes to this repository.

Start from current main, keep changes scoped, run documented checks and keep
documentation consistent. Never commit secrets, private exports or customer data.
