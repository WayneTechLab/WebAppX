## Selected implementation

F002 adds a bounded source browser with extension and metadata filters, stable
contained refusal reasons, canonical exact-case paths, linked-ancestor refusal,
file-size and write-kind metadata, and generated-file protection. It also adds
rule provenance, read-only policy proposal/comparison, strict encoding handling,
workspace-scoped optional navigation preferences and explicit metadata export.

A refreshed or filtered inventory must not silently move an editor to another
file. Inventory omission is not proof of deletion. An invalid picker selection
may clear only from adequate fresh evidence; the loaded draft and original base
remain available until an explicit editor action replaces them. A proposed
allowlist rule never grants read or write access.
