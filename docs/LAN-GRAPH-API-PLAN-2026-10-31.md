## Implementation scope

F005 adds a bounded canonical graph read model alongside the existing identity
and source-ownership model. It contains explicit page, node and reference
collections, ordered children, typed qualified lookup, component and collection
version checks, deterministic serialization and revisions, filtered findings,
accepted history, comparison and recovery. Unsupported source regions remain
opaque and read-only. A reviewed legacy-to-current migration produces an
isolated copy; applying that copy and accepting a graph are separate actions.
Graph metadata cannot grant source-write authority.

F006 adds a versioned graph API with discoverable query and command descriptors,
exact discriminated envelopes, input and response validation, bounded typed
errors, explicit pagination, null/absent semantics, public examples and metadata
export. Both the supported older contract and current contract must execute
under their own schemas. This new surface does not silently claim that every
legacy LAN route has become versioned. Unimplemented operations remain
unavailable.
