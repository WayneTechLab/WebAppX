## Repository access and contribution policy

WayneTechLab is the sole owner and maintainer. No other collaborator is added
at publication. Only WayneTechLab approves repository changes and invitations.
Public visibility allows people to read, clone, fork and suggest changes; those
actions do not grant write or administrative access to this repository.
Do not add co-authorship for automated tooling. Retain applicable licenses and
source attribution when creating a project from the template.
