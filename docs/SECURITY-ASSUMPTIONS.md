# Security assumptions and adoption register

This register addresses WX-0650. It records the assumptions under which the
reviewed template source is useful, and the evidence an adopted application
still needs. Source review date: **2026-10-15**; examined WebAppX revision:
**`f197affabfe125321c439d8a50854abe684c2355`** (**R1** below). This review
supplies no new runtime, emulator, provider or deployment result.

The [2026-10-05 security review](SECURITY-REVIEW.md) remains the original receipt
for that review. Its test counts, audit result, filesystem skips and production
limitations retain their original date and scope. The later
[session and portal review](SESSION-CONTRACTS-QA-2026-10-15.md) records its own
starting source base and local execution environment. A review date in this
register does not refresh either receipt's execution evidence.

## Recording a new observation

For an adopted application, retain the assumption ID, examined source revision,
original observation timestamp, host/architecture/runtime or provider/target,
exact action, outcome and evidence location. Record who accepts the adoption
requirement and the trigger that invalidates reuse. Keep secrets, real personal
data and workstation-specific runtime paths outside tracked template records.

Update the relevant assumption after reviewing new evidence; retain historical
receipts with their original dates and limits. The
[health vocabulary](MONITORING.md) gives separate states for source checks,
browser execution, owned local sessions, optional providers and deployed services.
